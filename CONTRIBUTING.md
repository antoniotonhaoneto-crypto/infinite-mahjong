# Contribuindo

1. Crie uma branch a partir de `main`.
2. Faça mudanças pequenas e documentadas; mantenha a versão jogável ao abrir `index.html`.
3. Verifique a sintaxe do JavaScript e teste manualmente seleção, combo, dica, shuffle, conclusão de fase, restauração após recarregar e reinício.
4. Atualize `README.md`, documentação e `CHANGELOG.md` quando houver alteração de comportamento.
5. Abra um pull request descrevendo alterações, testes realizados e eventuais limitações.

Não há licença definida nesta versão. Confirme as condições de uso antes de contribuir ou redistribuir.
